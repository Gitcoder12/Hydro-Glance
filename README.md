# Hydro-Glance
Hydro-Glance monitors real-time water anomalies to detect droughts, floods, and sea-level threats before they become disasters.

## Understanding the project

### In plain language

A proposed water-monitoring system that would help people notice unusual changes that may indicate flooding, drought or other water-related risks.

### Technical and research view

Concept-stage; no runnable water monitoring system exists.
