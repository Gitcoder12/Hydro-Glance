# Agent Instructions — Hydro-Glance

This is a concept-stage repository. Read the roadmap before implementation.

- Do not claim real-time monitoring, flood prediction or drought detection exists.
- Use a documented lawful dataset and preserve licence/attribution.
- Validate units, timestamps, timezone, missing data and sensor quality flags.
- Start with an interpretable baseline and evaluate false alarms/missed events.
- Do not issue emergency/public-safety advice or scrape restricted feeds.
- Work on a branch and submit a PR; human review is required before public release.
