# Contributing to Hydro-Glance

This is a concept-stage environmental-data project. Begin with one sourced historical dataset.

1. Read README.md and FEATURE_UPGRADE_PLAN.md.
2. Choose one bounded ingestion, schema, visualization or evaluation task.
3. Work on a feature branch.
4. Preserve dataset licence, attribution, units, timezone and source metadata.
5. Test missing data, sensor outages, duplicated timestamps and implausible readings.
6. Include exact source period, commands, results and limitations in the PR.

Do not publish public-safety warnings or real-time prediction claims without authoritative sources and validation. Human review is required.
